# Treasure Chest Loot Table Rebalance

same as in the `./villager-trade-rebalance.md`, we need to rebalance the enchantment that can be found in treasure chest or anychest loot that could give players items or specifically enchantments. currently the treasure chest loot table is too OP, it give high level enchantment and high level tool and armor that make the game too easy.

for the enchantment part, we should limit the maximum level of enchantment that can be found in treasure chest or anychest loot. for example, the maximum level of enchantment that can be found in treasure chest or anychest loot should be configurable in the config file.

for the tool and armor part, we should limit the maximum level of tool and armor that can be found in treasure chest or anychest loot. for example, the maximum level of tool and armor that can be found in treasure chest or anychest loot should be configurable in the config file.

the practice could be like from the `./villager-trade-rebalance.md`, we can create a config file for the treasure chest loot table rebalance.

we can adjust the loot table of enchantment (individually or globally) as enchantment book or tools/armors/weapon enchantment that can be found in anychest loot to be more balanced and not too OP by the configuration file.
