# Villager Trade Rebalance
we need to rebalance what enchantment that should be in villager trade with specific level or limit universally so the high level enchantment are not too easy to get, and for the tools and armor enchantment should be different.

as example, sharpness set to max at `400` and we can found it on villager (librarian) by chance and it only cost about `50 emerald` and `1 book` which completely broken.
so in that scenario, we can limit the maximum level of enchantment that can be traded by villager, or we can limit the chance of finding the enchantment in villager, or we can limit the price of the enchantment, or we can limit the type of enchantment that can be traded by villager.
